          MuScriptor
        

        
音频转 MIDI / 乐谱（Kyutai 出品，免费开源）—— 本站的上游

      

      
    


    

      怎么用 MuScriptor 得到能喂给本站的 .mid
      
    
        
  1. 打开 muscriptor.kyutai.org，点上传，选你的音频文件（mp3 / wav / flac 等）。
    2. 
        
  2. 等它转谱完成。它会自动识别乐器，钢琴曲通常直接给出一条钢琴轨。
    3. 
        
  3. 下载 .mid 文件（不要下 PDF 或吉他谱，本站要的是 MIDI）。
    4. 
        
  4. 回到本页，把这个 .mid 拖进上面的虚线框，点「转换」，再点「下载 .txt」。
    5. 
      

      

        提示：音频质量越干净、混音越简单，转出来的 MIDI 越准。
        如果是整首歌带人声和鼓，可以在 MuScriptor 里只保留钢琴轨再下载，效果会好很多。
      

    


    

      

        

          听谱 Hearscore
        

        
备选转换工具：浏览器本地识别 MP3 / WAV 音符，支持钢琴卷帘、原音变速播放、导出 MIDI / JSON

      

      
    


    

      MuScriptor 用不了？可以试试 Hearscore
      
    
        
  1. 打开 hear-score.lirentech.net，选择本地音频文件（MP3 / WAV）。
    2. 
        
  2. 它同样在浏览器里本地识别音符，不上传，能看到钢琴卷帘并试听。
    3. 
        
  3. 导出 MIDI 文件。
    4. 
        
  4. 回到本页，把 .mid 拖进上面的虚线框 → 转换 → 下载 .txt。
    5. 
      

      

        两个工具都免费、都在本地处理，可以都试一下：同一段音频用不同工具转出的 MIDI 会有差异，
        哪个在光遇 15 键上听着更像原曲就用哪个。
